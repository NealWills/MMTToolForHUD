# 0.6.0

Released: 2026-11-09 · [Performance report](../PerformanceReports/perf-report-0.6.0.md)

Initial public release.

## Toast

- Stackable capsules at the top, center or bottom, auto-dismissing in
  reverse order of appearance
- Success / error / info icons, long-text wrapping, never blocks touches

## Loading

- Spinner with optional multi-line text
- Touch interception: panel-only (`.blockHUD`), whole-screen
  (`.blockAll`) or fully pass-through

## Progress

- Bar and ring styles with live animated updates and an automatic
  percentage readout (clamped to 0...1)

## Status

- Auto-dismissing success (checkmark) and error (cross) flashes

## Core

- Per-window management: every show / dismiss call targets one window,
  so multiple windows display independent HUDs and toasts
- Thread-safe APIs: calls from any thread are dispatched to the main
  thread automatically
- Single value-type configuration (`MMTToolForHUDConfig`) for all
  appearance and behavior
- Stable hierarchical accessibility identifiers for XCUITest / Appium,
  plus an Appium end-to-end scaffold
- Example demo app and unit + performance test suites
