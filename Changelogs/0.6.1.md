# 0.6.1

Released: 2026-11-09 · [Performance report](../PerformanceReports/perf-report-0.6.1.md)

## Fixed

- Thread safety of all state getters (`config`, `isVisible`,
  `currentProgress`, toast visibility): background reads no longer race
  main-thread mutations
- Status icon tint and accessibility label are carried in the symbol
  mode payload instead of string-matching the SF Symbol name
- The `blockHUD` hit rect is derived from bounds + center so it stays
  stable while scale transforms animate
- Toast auto-remove bookkeeping is canceled before the detach guard,
  preventing work-item residue for externally removed items
- `hudMargin` is applied on container reconfiguration like every other
  option
- The content view applies the default configuration in `init`, so
  `preferredSize` never depends on `UILabel`'s implicit default font
- CI resolves the simulator dynamically (the macos-15 image lacked the
  pinned destination)
- The memory benchmark drains an autorelease pool per stress cycle:
  the ~19 MB delta was autoreleased temporaries, 300 cycles now settle
  at ~3.7 MB

## Added

- GitHub Actions workflow replacing the dead Travis CI config
- Spinner exposed as an accessibility element with a "Loading" label

## Changed

- Performance reports are named by version tag
  (`perf-report-<version>.md/.json`), keeping exactly one final report
  per tag
- README documents the `dismiss(after:)` semantics, the config
  value-type pitfall and the keyboard overlap limitation
