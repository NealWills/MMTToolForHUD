# 0.6.3

Released: 2026-11-10 · [Performance report](../PerformanceReports/perf-report-0.6.3.md)

## Added

- `MMTToolForHUD.version` — the library version string, queryable at runtime
- `MMTToolForHUD.versionDescription` — release notes for the current version
- Tests keeping `version` in sync with the podspec so the shipped value
  never drifts
- Demo app: an info button in the top-right corner showing the library
  version and its release notes via a toast (`demo.version` identifier)

## Changed

- The whole public API surface now lives in a single file
  (`MMTToolForHUD.swift`); the implementation files were renamed to
  `MMTToolForHUDPresenter.swift` and `MMTToolForHUDToastManager.swift`,
  and every other file is internal-only
- Every default color is now a fixed `UIColor(red:green:blue:alpha:)`
  value: dark mode never swaps HUD and toast colors anymore
  (`.systemGreen` / `.systemRed` / `.systemBlue` and grayscale
  initializers were replaced)

## Fixed

- Global-config leak between tests (`testStatusIconTintMatchesConfiguration`
  mutated the shared configuration without restoring it)
