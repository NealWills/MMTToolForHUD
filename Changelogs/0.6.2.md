# 0.6.2

Released: 2026-11-09 · [Performance report](../PerformanceReports/perf-report-0.6.2.md)

## Fixed

- Multi-line text measurement: explicit `\n` text and word-wrapped text
  now size the panel correctly and are never clipped
- NaN / infinite progress values (e.g. `current/total` with `total == 0`)
  are sanitized to zero instead of crashing the percent conversion
- The panel top edge is anchored while a HUD is visible, so the
  indicator never shifts when text changes line count (the panel grows
  downward instead)
- Indicator frames are seeded synchronously on HUD mode switches,
  removing the fly-in-from-corner transition when a loading HUD switches
  to progress
