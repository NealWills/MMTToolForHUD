# 0.6.4

Released: 2026-11-27 · [Performance report](../PerformanceReports/perf-report-0.6.4.md)

## Added

- Configurable shadow appearance for HUD panels:
  `hudShadowColor`, `hudShadowOpacity`, `hudShadowRadius`, and
  `hudShadowOffset`
- Configurable shadow appearance for toast items:
  `toastShadowColor`, `toastShadowOpacity`, `toastShadowRadius`, and
  `toastShadowOffset`
- Demo controls for customized HUD and toast shadows
- Complete Appium coverage for every interactive demo control
- JSON and Markdown Appium reports with one screenshot per test

## Changed

- Raised the minimum supported iOS version from 13.0 to 15.0 for
  compatibility with Xcode 27 and current CocoaPods lint builds
- Upgraded the Appium test stack to Appium 4, WebdriverIO 10, and the
  XCUITest driver 13
- Updated Appium capabilities and simulator selection for iPhone 18 Pro
- Updated runtime `MMTToolForHUD.version` and `versionDescription` metadata

## Fixed

- HUD and toast panels now keep their shadow outside the clipped panel
  bounds by switching from clipped to non-clipped rounded-panel rendering
- Appium tests now handle stacked toasts and stale elements reliably
- Appium scroll navigation reliably reaches bottom-of-screen demo controls
